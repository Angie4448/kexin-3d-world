# 给学生做 3D 世界之前，先填这张表

填完后，整张表连同 `01-发给通用AI.txt` 或 `02-发给工作搭子.txt` 一起贴进对话框。

不要填学生真名、学校名、班级号、成绩、聊天记录。已读材料请用老师自己的话概括，不要把学生笔记原文整段粘贴。

---

```
【科创 3D 世界 · 老师填写】

1. 学生化名（会出现在片尾「DIRECTED BY …」和胶卷记录里）：
   （例：小河、阿洛、导演A。不要用真名，也不要用网名里能认出人的字。）

2. 年级：
   （例：高一 / 高二）

3. 设备（可多选）：
   [ ] 电脑（键盘 + 鼠标）
   [ ] 平板（手指触摸）
   [ ] 两个都要（同一页面里自动切换）

4. 学生在 3D 里的角色：
   [ ] 参与者：缩小成分子 / 粒子 / 材料本身，亲手做实验步骤
   [ ] 旁观者：跟着镜头走，看过程、读数据，少动手

5. 已经读过的材料（用老师的话写 200–500 字，按兴趣方向分条。
   写清：学生已经知道什么、还卡在什么、希望 3D 里再体验哪一步）：


6. 兴趣方向（3–8 个。每个写：方向名称 + 一句科学问题。
   必须来自学生已经感兴趣、已经读过的内容，不要临时另出题）：
   1)
   2)
   3)
   4)
   5)
   6)

7. 希望网站做完后学生立刻写什么（可改，下面是默认）：
   写下自己在每个世界里观察到的现象，再对照阅读材料：
   对得上的写下来，对不上的也写下来。最后用一句话回答：
   如果只能留一个课题，我选哪个，为什么。

8. 交付方式（可多选）：
   [ ] 一个能下载的 .html 文件（发给学生双击打开）
   [ ] 一个云端链接（发给学生点开就能玩）
```
