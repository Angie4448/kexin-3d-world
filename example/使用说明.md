# 示例怎么打开

文件：`example/index.html`  
引擎已内嵌，双击即可，不需要安装，也不需要联网。

1. 用 Chrome 或 Edge 打开（不建议用微信内置浏览器）。
2. 点「开机 ACTION」。
3. 再点一下画面，进入第一人称。
4. 走到六个沙盘前按 `E` 进入；按 `R` 回剪辑室。
5. 收齐六枚胶卷后，终章解锁。

若双击后是一片黑、或鼠标转不了：先点一下画面，再看屏幕下方提示。按 `Esc` 可以松开鼠标，去点菜单。

本示例主题是纳米表面改性，只作「做好之后长什么样」的参考。给学生做新的一份时，请用仓库 `prompts/` 里的表和提示词，换成该学生自己的兴趣方向。
